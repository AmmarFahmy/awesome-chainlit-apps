## 🛠️ Development

### Adding a New App

1. Create a new directory with your app name
2. Include all necessary files (`app.py`, `requirements.txt`, `README.md`)
3. Add Chainlit configuration in `.chainlit/config.toml`
4. Update the main README table
5. Submit a pull request

### Conversion Guidelines

When converting from Streamlit:
- Maintain original functionality
- Enhance with Chainlit-specific features (starters, settings, etc.)
- Include proper attribution to original authors
- Test thoroughly

## 🤝 Contributing

We welcome contributions! Here's how you can help:



### 📝 Contribution Process

1. **Fork** the repository
2. **Create** a feature branch (`git checkout -b feature/amazing-app`)
3. **Commit** your changes (`git commit -m 'Add amazing app'`)
4. **Push** to the branch (`git push origin feature/amazing-app`)
5. **Open** a Pull Request

### 🎨 Quality Standards

- **Code Quality**: Clean, well-documented code
- **User Experience**: Intuitive and responsive interfaces
- **Documentation**: Clear setup and usage instructions
- **Attribution**: Proper credit to original authors (for conversions)
- **Testing**: Apps should work out of the box

### 🔍 App Acceptance Criteria

- ✅ Follows Chainlit best practices
- ✅ Includes proper documentation
- ✅ Has clear setup instructions
- ✅ Demonstrates a valuable functionality
